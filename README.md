# Leashaniya Krishnapillai — Portfolio (Vite + React)

## Run it locally

1. Install dependencies:
   npm install

2. Start the dev server:
   npm run dev

3. Open the URL it prints (usually http://localhost:5173) in your browser.

Any time you edit src/Portfolio.jsx and save, the browser updates automatically —
that's how you'll see changes live as we make them.

## Build for deployment (e.g. GitHub Pages)

   npm run build

This outputs a production-ready `dist/` folder you can deploy.
